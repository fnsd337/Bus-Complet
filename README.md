# أتوبيس كومبليت

لعبة كلمات عربية متعددة اللاعبين مبنية بـ Next.js وReact وTypeScript وSupabase. الغرف والجولات والإجابات والنقاط محفوظة في Postgres؛ وتصل التغييرات إلى اللاعبين عبر Supabase Realtime. لا تستخدم الواجهة بيانات لعب محلية بديلة.

## تشغيل اللعب أونلاين

### ١. إنشاء مشروع Supabase

1. أنشئ مشروعًا جديدًا من [supabase.com](https://supabase.com/).
2. من زر **Connect** أو **Settings → API Keys** انسخ **Project URL** و**Publishable key**.
3. من **Authentication → Providers** فعّل تسجيل الدخول المجهول **Anonymous Sign-Ins**؛ لا يحتاج اللاعب إلى بريد أو كلمة مرور.
4. افتح **SQL Editor** وشغّل كامل ملف [`supabase/migrations/202611190001_game.sql`](supabase/migrations/202611190001_game.sql). ينشئ الجداول، وسياسات RLS، ودوال التحقق والحساب، ويضيف الجداول إلى نشر Realtime.

### ٢. إعداد المتغيرات وتشغيل التطبيق

من مجلد المشروع:

```powershell
Copy-Item .env.example .env.local
```

افتح `.env.local` وضع القيم التي نسختها:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_your-key
```

ثم شغّل:

```powershell
npm install
npm run dev
```

افتح `http://localhost:3000`. تحتاج Next.js 16 إلى Node.js 20.9 أو أحدث. يقبل التطبيق مفتاح `Publishable` الحديث، كما يقبل مفتاح `anon` للمشاريع الأقدم. لا تضع `Secret` أو `service_role` في الواجهة أو في متغير يبدأ بـ `NEXT_PUBLIC_`.

### ٣. النشر على Vercel ومشاركة اللعبة

1. ارفع هذا المجلد إلى مستودع Git، ثم استورده من لوحة Vercel.
2. في **Project Settings → Environment Variables** أضف `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` لبيئات Production وPreview.
3. انشر المشروع. انسخ رابط Vercel، ثم أنشئ غرفة وشارك رابط الدعوة أو كود الغرفة مع أصحابك.

قبل الإطلاق، أضف نطاق Vercel إلى **Authentication → URL Configuration → Redirect URLs** في Supabase. لا يحتاج تسجيل الدخول المجهول إلى مسار تحويل، لكن إعداد عنوان الموقع يسمح باستخدام الروابط والنطاقات المنشورة بوضوح.

## ما تتضمنه اللعبة

- إنشاء غرفة بكود ورابط دعوة، وانضمام برمز، وصور رمزية، وحالة استعداد، ومضيف.
- من ٢ إلى ١٠ لاعبين، وجولات من ٣ أو ٥ أو ٧ أو ١٠، ومؤقت ٣٠ أو ٦٠ أو ٩٠ أو ١٢٠ ثانية، واختيار الحرف والفئات.
- حفظ تلقائي للإجابات، ومن دون مؤقت: أول لاعب يكمل الفئات ويعلن «أتوبيس كومبليت» يقفل الجولة عند جميع اللاعبين وينقلهم للمراجعة.
- حساب نقاط مركزي داخل قاعدة البيانات: ١٠ للإجابة الصحيحة الفريدة، و٥ للإجابة الصحيحة المكررة، وصفر للإجابة الفارغة أو التي لا تبدأ بالحرف.
- تطبيع عربي للتشكيل والتطويل وأشكال الألف والياء والألف المقصورة وعلامات الترقيم والمسافات.
- عرض النتائج وسجل الجولات والتصويت على الإجابات المختلف عليها وتصحيح المضيف مع إعادة حساب النقاط.
- تفاعلات فورية، ومغادرة وإعادة اتصال، ونقل دور المضيف عند انقطاعه، وإعادة المباراة.
- تصميم RTL متجاوب للهاتف واللوحي والكمبيوتر، ووضع داكن/فاتح، ومؤثرات صوتية اختيارية، وحركات تحترم إعداد تقليل الحركة في الجهاز.

لا توجد قائمة قاموس عربية شاملة داخل التطبيق؛ لذا يعتبر الحساب الآلي الإجابة غير الفارغة التي تبدأ بالحرف صالحة مبدئيًا، وتتيح شاشة النتائج مراجعتها بالتصويت وتصحيح المضيف. هذا يمنع الادعاء بأن فحص البداية وحده يثبت صحة المعنى.

## فحوصات المشروع

```powershell
npm test
npm run typecheck
npm run build
```

الاختبار متعدد الأجهزة يتطلب مشروع Supabase حقيقيًا ومفتاحيه. بعد إدخالهما، افتح رابط Vercel في متصفحين أو جهازين، أنشئ غرفة، انضم بالكود، واستكمل جولة للتأكد من التزامن بين الطرفين.
